# Proyecto Web - Documentación

Este archivo contiene información adicional para el equipo de desarrollo.

## Entorno

- Backend: Java
- Frontend: Angular

## Despliegue

Antes de realizar un despliegue se debe verificar:

- Conectividad con los servicios externos.
- Espacio disponible en disco.
- Estado de los procesos.
- Registros de la aplicación.
